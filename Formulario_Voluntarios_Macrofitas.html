Siga os passos abaixo uma única vez para ativar o envio centralizado:
  1. Acesse formspree.io → crie uma conta gratuita com seu e-mail.
  2. Clique em "New Form", dê um nome (ex: Voluntários Macrófitas) e confirme.
  3. Copie o Form ID mostrado (ex: xpwzabcd).
  4. Abra este arquivo HTML no VS Code e substitua SEU_ID_FORMSPREE_AQUI pelo ID copiado (linha indicada no script).
Plano gratuito: até 50 inscrições/mês. Cada envio chega no seu e-mail e fica salvo no painel do Formspree.
