⚙️ Configuracion necesaria para recibir inscripciones por correo (Formspree)
Siga los pasos siguientes una sola vez para activar el envio centralizado:
  1. Acceda a formspree.io y cree una cuenta gratuita con su correo.
  2. Haga clic en "New Form", asigne un nombre (ej.: Voluntarios Macrofitas) y confirme.
  3. Copie el Form ID mostrado (ej.: xpwzabcd).
  4. Abra este archivo HTML en VS Code y sustituya SEU_ID_FORMSPREE_AQUI por el ID copiado (linea indicada en el script).
Plan gratuito: hasta 50 inscripciones/mes. Cada envio llega a su correo y queda guardado en el panel de Formspree.
